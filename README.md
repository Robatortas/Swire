# Swire
Swire is a desktop application that allows the user to create their own sinks for the purpose of combining several audio signals.

The idea originally came into my head when wanting to configure two speakers with the same audio as the output, which was a hassle using tools like pipewire or pulseaudio.

The name is a combination of the words 'Synked' and 'Wire'. 'Synked' is a playword for synchronized and sink.
